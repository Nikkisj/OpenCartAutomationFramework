# OpenCart Selenium Automation Framework

## Project Description

Developed a Hybrid Selenium Automation Framework for TutorialsNinja OpenCart application using:

- Selenium WebDriver
- Java
- TestNG
- Maven
- Apache POI
- Extent Reports
- Jenkins
- GitHub

Implemented:

- Page Object Model (POM)
- Parallel Execution
- Cross Browser Testing
- ThreadLocal Driver Management
- Data Driven Testing
- Screenshot on Failure
- Extent Reports
- Jenkins CI/CD Integration
